# Настройка целей в Яндекс.Метрике для квизов

## Цели для отслеживания

В проекте настроены следующие цели в Яндекс.Метрике:

### 1. Завершение основного квиза
- **Название цели**: `quiz_completed`
- **Описание**: Клиент завершил основной квиз и получил купон
- **Параметры события**:
  - `discount` - размер скидки
  - `business_type` - тип бизнеса (ip/ooo/both)
  - `phone` - номер телефона (маскированный)
  - `coupon` - код купона

### 2. Завершение квиза тарифов
- **Название цели**: `quiz_tariff_completed`
- **Описание**: Клиент завершил квиз тарифов и получил купон
- **Параметры события**:
  - `discount` - размер скидки
  - `business_type` - тип бизнеса (ip/ooo/both)
  - `phone` - номер телефона (маскированный)
  - `coupon` - код купона

## Настройка в Яндекс.Метрике

### Шаг 1: Получение ID счетчика
1. Зайдите в [Яндекс.Метрику](https://metrika.yandex.ru/)
2. Выберите ваш счетчик
3. Скопируйте ID счетчика (цифры в URL)

### Шаг 2: Добавление переменной окружения
Создайте файл `.env.local` в корне проекта:
```
NEXT_PUBLIC_YANDEX_METRICS_ID=ВАШ_ID_СЧЕТЧИКА
```

### Шаг 3: Создание целей в Яндекс.Метрике
1. В настройках счетчика перейдите в "Цели"
2. Нажмите "Добавить цель"
3. Выберите тип "JavaScript событие"
4. Создайте две цели:

#### Цель 1: Завершение основного квиза
- **Название**: "Завершение основного квиза"
- **Условие**: `quiz_completed`
- **Описание**: "Клиент завершил основной квиз и получил купон"

#### Цель 2: Завершение квиза тарифов
- **Название**: "Завершение квиза тарифов"
- **Условие**: `quiz_tariff_completed`
- **Описание**: "Клиент завершил квиз тарифов и получил купон"

### Шаг 4: Добавление кода Яндекс.Метрики

## Тестирование

### Проверка отправки событий
1. Откройте консоль браузера (F12)
2. Пройдите один из квизов до конца
3. В консоли должно появиться сообщение:
   ```
   📊 Яндекс.Метрика: отправлено событие "quiz_completed" {discount: 25, business_type: "ip", ...}
   ```

### Проверка в Яндекс.Метрике
1. Зайдите в отчет "Цели" в Яндекс.Метрике
2. Проверьте, что цели срабатывают при завершении квизов
3. В отчете "События" должны появляться события `quiz_completed` и `quiz_tariff_completed`

## Дополнительная информация

### Параметры событий
Все события отправляются с дополнительными параметрами для лучшей аналитики:
- `discount` - размер скидки в рублях
- `business_type` - тип бизнеса клиента
- `phone` - номер телефона (для отслеживания уникальных клиентов)
- `coupon` - код купона (для связи с базой данных)

### Безопасность
- Номера телефонов отправляются в замаскированном виде
- Все данные передаются через защищенное соединение
- События отправляются только при успешном завершении квиза

### Отладка
Если события не отправляются:
1. Проверьте, что код Яндекс.Метрики загружен
2. Убедитесь, что ID счетчика указан правильно
3. Проверьте консоль браузера на наличие ошибок
4. Убедитесь, что файл `.env.local` создан и содержит правильный ID
