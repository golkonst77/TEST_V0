### 3. Система версионирования ✅

**Версия**: 1.0.20  
**Дата**: 28.11.2025

#### Проблема:
- Версия дублировалась в двух местах: `package.json` и `public/version.json`
- Риск рассинхронизации версий
- Необходимость ручного обновления двух файлов

#### Решение - Single Source of Truth:
- **package.json** - единственный источник версии
- **Удален** `public/version.json` полностью
- **Создан** API endpoint `/api/version` для динамического чтения

#### Как работает:
1. **Git hook** перехватывает коммит
2. **Скрипт** `scripts/update-version.cjs` обновляет `package.json`
3. **API** `/api/version` читает версию из файловой системы
4. **Компонент** `components/version-info.tsx` получает версию через fetch
5. **Changelog** автоматически обновляется

#### Команды:
```bash
npm run version:patch  # 1.0.0 → 1.0.1 (багфиксы)
npm run version:minor  # 1.0.0 → 1.1.0 (новые функции)
npm run version:major  # 1.0.0 → 2.0.0 (breaking changes)
```

#### Преимущества:
- ✅ Невозможно рассинхронизировать версии
- ✅ Всегда актуальная версия в API
- ✅ Меньше файлов для поддержки
- ✅ Автоматическое обновление changelog
- ✅ Префикс версии в сообщениях коммитов
