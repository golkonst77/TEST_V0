## [1.0.20] - 2025-11-28 - Рефакторинг системы версионирования (Single Source of Truth)

### Изменено
- **Система версионирования**: Полный рефакторинг - теперь `package.json` является единственным источником истины
- **API endpoint `/api/version`**: Создан новый endpoint, который динамически читает версию из package.json
- **VersionInfo компонент**: Обновлен для использования API вместо статического файла
- **Скрипт обновления**: Упрощен - теперь обновляет только package.json

### Удалено
- **`public/version.json`**: Удален полностью - больше не нужен
- Дублирование версии в двух местах

### Преимущества
- ✅ **Single Source of Truth**: Версия хранится только в одном месте (package.json)
- ✅ **Автоматическая синхронизация**: Невозможно рассинхронизировать версии
- ✅ **Динамическое чтение**: API всегда возвращает актуальную версию
- ✅ **Упрощение**: Меньше файлов для поддержки
- ✅ **Надежность**: Нет риска забыть обновить один из файлов

### Технические детали
- API: `app/api/version/route.ts` - читает package.json с файловой системы
- Компонент: `components/version-info.tsx` - использует fetch('/api/version')
- Скрипт: `scripts/update-version.cjs` - обновляет только package.json
- Fallback: При ошибке API возвращает последнюю известную версию
