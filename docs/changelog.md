## [2024-12-19] - Критические исправления мобильной адаптации

### Исправлено
- Добавлены кастомные брейкпоинты в tailwind.config.ts (xs: 320px, sm: 640px, md: 768px, lg: 1024px, xl: 1280px, 2xl: 1536px)
- Исправлена Header секция:
  - Убраны фиксированные высоты, добавлены responsive высоты (h-16 md:h-20)
  - Адаптированы кнопки с responsive размерами (px-4 md:px-6 py-2 md:py-3)
  - Добавлен max-height и overflow-y-auto для мобильного меню
  - Улучшена типографика (text-sm md:text-base)

- Исправлена Hero секция:
  - Убраны фиксированные отступы и marginLeft/marginTop
  - Изменен layout с text-left на text-center для лучшей мобильной адаптации
  - Адаптированы размеры заголовков (text-2xl md:text-3xl lg:text-4xl xl:text-5xl)
  - Улучшена grid-система feature cards (grid-cols-1 md:grid-cols-2 lg:grid-cols-3)
  - Добавлены responsive отступы и размеры для всех элементов

- Добавлены базовые стили в globals.css:
  - overflow-x: hidden для предотвращения горизонтальной прокрутки
  - box-sizing: border-box для всех элементов
  - Кастомные контейнеры для разных брейкпоинтов
  - Правильные padding для мобильных устройств

### Изменено
- Применен mobile-first подход во всех секциях
- Улучшена читаемость на маленьких экранах
- Оптимизированы размеры элементов для touch-интерфейса
- Исправлены проблемы с горизонтальной прокруткой
