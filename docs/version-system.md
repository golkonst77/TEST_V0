# Система версионирования

## Концепция: Single Source of Truth

Версия проекта хранится **только в одном месте** - `package.json`.

## Как это работает

### 1. Источник версии
```json
// package.json
{
  "version": "1.0.20"
}
```

### 2. API endpoint
**Файл**: `app/api/version/route.ts`

**URL**: `GET /api/version`

**Функция**: Динамически читает `package.json` и возвращает:
```json
{
  "version": "1.0.20",
  "build": "1020",
  "date": "2025-11-28",
  "description": "..."
}
```

### 3. Компонент VersionInfo
**Файл**: `components/version-info.tsx`

**Функция**: Получает данные из API и отображает в футере сайта

## Обновление версии

### Вручную
Отредактируйте `package.json`:
```json
{
  "version": "1.0.21"
}
```

### Через скрипт (рекомендуется)
```bash
# Patch: 1.0.20 → 1.0.21
npm run version:patch

# Minor: 1.0.20 → 1.1.0
npm run version:minor

# Major: 1.0.20 → 2.0.0
npm run version:major
```

Скрипт автоматически:
- Читает текущую версию из package.json
- Увеличивает номер версии
- Сохраняет обратно в package.json
- Выводит информацию о новой версии

## Преимущества

✅ **Нет дублирования** - версия в одном месте  
✅ **Невозможно рассинхронизировать** - один источник истины  
✅ **Автоматическая актуальность** - API всегда читает свежую версию  
✅ **Простота** - меньше файлов для поддержки  
✅ **Стандартность** - используется стандартный package.json  

## Миграция со старой системы

### Было (до v1.0.20):
- ❌ Версия в `package.json`
- ❌ Версия в `public/version.json`
- ❌ Нужно обновлять оба файла
- ❌ Риск рассинхронизации

### Стало (с v1.0.20):
- ✅ Версия только в `package.json`
- ✅ API динамически читает версию
- ✅ Один файл для обновления
- ✅ Всегда синхронизировано

## Fallback

Если API не может прочитать package.json (невозможная ситуация в production), возвращается fallback версия:

```json
{
  "version": "1.0.20",
  "build": "1020", 
  "date": "2025-11-28",
  "description": "Fallback version"
}
```

## Проверка версии

### В браузере
Откройте сайт → прокрутите вниз → внизу футера отображается версия

### Через API
```bash
curl https://prostoburo.com/api/version
```

### В консоли браузера
```javascript
fetch('/api/version')
  .then(r => r.json())
  .then(console.log)
```
