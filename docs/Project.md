# ПростоБюро - Документация проекта

## Обзор проекта

**ПростоБюро** - это современный веб-сайт юридической компании, предоставляющей профессиональные услуги по регистрации бизнеса, бухгалтерии и юридическому сопровождению. Проект представляет собой полнофункциональный сайт с интеграциями, системой лидогенерации и полным соответствием законодательству РФ.

**Текущая версия**: 1.0.22  
**Дата последнего обновления**: 28 ноября 2025

### Основные цели

1. **Привлечение клиентов** через интерактивный квиз с купонами и скидками
2. **Автоматизация обработки заявок** через интеграцию с AmoCRM и WhatsApp
3. **Соответствие законодательству РФ** (ФЗ-152, требования Роскомнадзора)
4. **Управление контентом** через административную панель
5. **Аналитика поведения** пользователей через Яндекс.Метрику

## Архитектура проекта

- **Деплой**: Vercel (автоматический при пуше в main)
- **Версионирование**: Git hooks + автоматические скрипты

## Функциональные модули

### 1. Система отзывов

#### Архитектура парсинга отзывов

```
Яндекс.Карты → Python Parser → JSON File → Next.js API → Frontend
```

**Компоненты:**
- `scripts/yandex_parser.py` - Python скрипт для парсинга
- `app/api/generate-yandex-json-remote/route.ts` - API для удаленного парсинга
- `app/api/local-reviews/route.ts` - API для локального отображения
- `components/reviews.tsx` - Frontend компонент

#### Процесс работы

1. **Парсинг**: Python скрипт извлекает отзывы с Яндекс.Карт по `companyId`
2. **Сохранение**: Отзывы сохраняются в JSON файл в папке `public/`
3. **Отображение**: Next.js API читает JSON и отображает отзывы на фронтенде
4. **Пагинация**: Клиентская пагинация по 3 отзыва на страницу

#### Ключевые особенности

- **Случайное перемешивание** отзывов при каждом запросе
- **Парсинг русских дат** (например, "4 марта" → ISO формат)
- **Fallback система**: если Supabase недоступен, используется локальный JSON
- **Обработка 39 отзывов** с полной информацией

### 2. Административная панель

**Маршруты:**
- `/admin/reviews` - Управление отзывами
- `/admin/settings` - Настройки сайта

**Функции:**
- Импорт отзывов из JSON файлов
- Генерация JSON из Яндекс.Карт
- Управление настройками сайта

### 3. API Endpoints

#### Отзывы
- `GET /api/local-reviews` - Получение локальных отзывов
- `POST /api/generate-yandex-json-remote` - Генерация JSON из Яндекс.Карт
- `POST /api/import-yandex-reviews-json` - Импорт отзывов в Supabase

#### Настройки
- `GET /api/settings` - Получение настроек сайта
- `POST /api/settings` - Обновление настроек

#### Диагностика
- `GET /api/test-supabase-simple` - Тест подключения к Supabase
- `GET /api/debug-env` - Отладка переменных окружения

## Технические решения

### 1. Обработка кодировки

**Проблема**: Специальные символы в именах файлов вызывали ошибки
**Решение**: Использование `stdin/stdout` для передачи данных между Node.js и Python

### 2. Парсинг русских дат

**Проблема**: Яндекс.Карты возвращают даты в формате "4 марта"
**Решение**: Создана функция `parseRussianDate()` для конвертации в ISO формат

### 3. Fallback система

**Проблема**: Supabase недоступен в некоторых случаях
**Решение**: Локальный JSON файл как резервный источник данных

### 4. Ограничение парсера

**Проблема**: Парсер извлекал только 5 отзывов из 39
**Решение**: Удалено ограничение `[:5]` в Python скрипте
